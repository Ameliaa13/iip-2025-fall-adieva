3. Работа с товарами
Добавление товара

    В главном меню выберите "1. Управление товарами"

    В подменю выберите "1. Добавить товар"

    Введите информацию о товаре:

        Название товара (например: Кофеварка)

        Цену (например: 15000.50)

        Количество на складе (например: 10)

Программа автоматически присвоит товару уникальный номер (ID).
Просмотр всех товаров

    В меню товаров выберите "2. Просмотреть все товары"

    На экране появится список всех товаров в формате:
    text

Product{id=1, name='Кофеварка', price=15000.50, quantity=10}
Product{id=2, name='Чайник', price=5000.00, quantity=15}

Поиск товара по номеру

    В меню товаров выберите "3. Найти товар по ID"

    Введите номер товара (ID)

    Программа покажет информацию об этом товаре

Удаление товара

    В меню товаров выберите "4. Удалить товар"

    Введите номер товара (ID)

    Товар будет удален из системы

4. Оформление продаж
Создание новой продажи

    В главном меню выберите "2. Создать продажу"

    Введите данные:

        ID товара (номер товара из списка)

        Количество (сколько единиц продается)

        Имя клиента (для учета)

Что происходит при продаже

    Программа проверяет, есть ли достаточное количество товара

    Рассчитывает сумму продажи (цена × количество)

    Уменьшает остаток товара на складе

    Сохраняет информацию о продаже с текущей датой и временем

5. Просмотр истории продаж

    В главном меню выберите "3. Просмотр всех продаж"

    Вы увидите список всех оформленных продаж в формате:
    text

Sell{id=1, productId=1, quantity=1, total=15000.50, customer='Иванов', date=2024-01-15T14:30:00}

Каждая запись содержит:

    Номер продажи (id)

    Номер проданного товара (productId)

    Количество (quantity)

    Общую сумму (total)

    Имя клиента (customer)

    Дата и время продажи (date)

6. Анализ статистики
Получение отчета за период

    В главном меню выберите "4. Статистика продаж за период"

    Введите начальную дату в формате ДД.ММ.ГГГГ (например: 01.01.2024)

    Введите конечную дату в формате ДД.ММ.ГГГГ (например: 31.01.2024)

Что вы получите в отчете

Программа покажет:

    Общее количество продаж за указанный период

    Общую выручку (сумму всех продаж)

    Общее количество проданных товаров (в штуках)

    Среднюю сумму одной продажи

    Подробный список всех продаж за этот период
